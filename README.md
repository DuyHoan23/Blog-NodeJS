# 📝 Node.js Blog Application

A simple **Blog web application** built with **Node.js**, created to practice and understand the fundamentals of server-side development.

This project focuses on core concepts such as routing, authentication, CRUD operations, and basic page rendering.

---

## 🚀 Project Overview

The Node.js Blog Application allows users to:
- Register and log in
- View a list of blog posts
- Create new blog posts
- Access static pages such as About and Contact

The project is intentionally kept simple to help developers become familiar with **Node.js workflows and web application structure**.

---

## ✨ Features

- User registration and login
- Authentication and session handling
- Create and display blog posts
- Blog post listing
- About page
- Contact page
- Simple and clean UI

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- EJS / Pug / Handlebars
- MongoDB / JSON / In-memory data 
- HTML, CSS

---

## ⚙️ Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/DuyHoan23/Blog-NodeJS.git
2. Install dependencies:
npm install
3. Run the application
npm start
4. Open the browser and visit:
http://localhost:3000
```

## Purpose of This Project

Learn Node.js basics

Practice Express routing

Understand authentication flow

Work with CRUD operations

Get familiar with MVC-style project structure
